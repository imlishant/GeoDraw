# Feedback

Drop screenshots and screen recordings here, then mention the file name in chat.

- Screenshots (`.png`, `.jpg`): can also just be pasted into the chat.
- Recordings (`.mov`, `.mp4`): put them here — frames get extracted with ffmpeg and reviewed step by step.
- A one-line note per file helps: *what you did → what you expected → what happened*, and the device (phone / iPad / laptop).

Everything in this folder except this README is ignored by git, so large videos never end up in the repo.
